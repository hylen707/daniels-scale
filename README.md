# ⚖ 다니엘의 저울

학교 학생회 상·벌점 관리 시스템

## 현재 상태
실행 가능한 Next.js MVP가 feature/mvp-site 브랜치에 구현되어 있습니다.

## 구현된 기능
- 대시보드 / 학생 검색
- 선도부 ↔ 사생회 역할 전환
- 선도부와 사생회 모두 벌점 입력
- 사생회 화면의 '+ 벌점 항목 추가' 버튼
- 학생 선택
- 지각 / 복장불량 / 신발장 미정리 / 선생님 재량 벌점 / 직접 입력
- 벌점 점수 입력
- 기입자 직접 입력
- 반성문 제출 체크
- 벌점 기록과 입력 역할 표시
- 기본 체력훈련 대상 표시

## 실행 방법
npm install
npm run dev

그 다음 브라우저에서 http://localhost:3000 을 엽니다.
